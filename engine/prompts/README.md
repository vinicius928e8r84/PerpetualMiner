# Prompt panel

Edit these files directly to change the pipeline prompts:

- `prompts/en_main_card.txt` - English main card generation
- `prompts/en_additional_card.txt` - English additional card generation
- `prompts/ru_card.txt` - Russian card generation used by the pipeline
- `prompts/ru_card_legacy.txt` - Previous Russian prompt kept for reference

The app loads these files at runtime, so future prompt changes live in one place.
