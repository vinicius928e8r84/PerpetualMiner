# The day rollover of automatic mining is an alarm set again at each firing

The rollover to a new day of automatic mining is an alarm set for the next local midnight that fires once and is scheduled again at each firing, instead of repeating every 24 hours: a fixed period would slip an hour forever at the first daylight saving change, and yesterday's badge would stay on the toolbar until 1 am. The alarm survives the service worker, and creating it again at each wake-up would push midnight away, so it is created only when missing; after it fires it is gone, and the listener schedules the next one. The rollover does not rewrite the diary: `getAutoMinerState` normalizes it by the rules of `MineracaoDoDia`, and the listener refreshes the badge and publishes the state even without a new phrase. On Chrome's start the badge does not come back alone, so listening to the start wakes the service worker, which does the work at the end of the file. `e2e/tests/mineracao-automatica-virada.spec.js` is the regression.
