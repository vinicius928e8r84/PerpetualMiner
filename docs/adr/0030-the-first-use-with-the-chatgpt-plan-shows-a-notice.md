# The first use with the ChatGPT plan shows a notice

The guidelines of OpenAI for "Sign in with ChatGPT" ask that an app using the person's plan say so the first time. The panel shows that notice once per computer, remembered in the extension's storage, and the usage page of ChatGPT (where the person sees the use and disconnects the app) is offered as "Gerenciar uso". This is a constraint from outside the code: removing the notice breaks the guidelines, not a test.
