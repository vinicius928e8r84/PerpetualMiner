# The overlay does not inherit from the site, and the site does not change it

The overlay lives in a shadow root on the page of the site, where any site stylesheet and fonts can reach it. Three choices keep it the same everywhere. Its start point is zero (`all: initial`), so nothing the site inherits reaches it. The host's own rules are written inline and with `!important`, so a stylesheet of the page can neither hide nor move it. And its fonts are registered in the document through the `FontFace` API under names only the overlay uses, because Chrome ignores the `@font-face` of `veio/tokens.css` inside a shadow root: the site never asks for those names, and a Manrope the site happens to have does not change the drawing. Clicks on the overlay stop propagating, so they are not clicks on the site (a player would pause the video).
