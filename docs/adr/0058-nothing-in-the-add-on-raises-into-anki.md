# Nothing in the add-on raises into Anki

Whatever the add-on does inside Anki (loading, the HTTP server, the Qt callbacks, the logger) must not leave an error for Anki, because Anki opens its own error dialog blaming the add-on. So loading never raises (everything goes to the logger), every callback Anki calls goes through `janela.protegido`, and the server turns any error into a 500 and never touches Anki's process (proxy, stdout, stderr, `excepthook`, warnings). The log handler opens the file for each record and releases it at once, because on Windows a log held open in `user_files` makes Anki's backup of that folder (a rename) fail: "Atualizar Extensões" then fails silently and "Remover" leaves the Conexão half deleted. The logger writes nowhere else: not to the root logging, not to stdout or stderr.
