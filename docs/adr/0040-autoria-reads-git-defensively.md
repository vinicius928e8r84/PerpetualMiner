# autoria.js reads git defensively

`scripts/ci/autoria.js` checks and repairs the authorship of the commits of a branch, and four choices in it look like excess. The rebase that rewrites messages runs with `commit.cleanup=whitespace`, because with the `commit.cleanup=strip` of whoever runs it the lines that start with `#` would be dropped from the messages. Trimming spaces, tabs and `\r` at the ends of a text is a loop, not a regular expression, because the equivalent expression backtracks quadratically on a line with many spaces. The log is read without an output limit (the whole messages of a long branch pass the 1 MB Node gives by default) and with `--no-show-signature` (with `log.showSignature` on, the signature line would come before each record). And the ends a clone does not have are asked for explicitly, because the shallow checkout of the CI does not bring the base.
