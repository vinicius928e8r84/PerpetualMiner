# A Cartão with no image still goes, but a Cartão with no audio does not

Image and audio are extras of a Cartão, and they fail in different ways because the person asked for them differently.

**Image: only the image fails.** Any error in the search, the judge, the triage, the generation or the conversion ends the choice without an image; the Cartão is `added` and the Envio `completed`. It costs saying "Enviado" about a Cartão with no picture, and the person sees the difference only in the Anki, since the screen has no state for "sem imagem" and none was invented. Without a key, the Cartão goes without image and the next one stops the Envio with `openai_key_missing`. The generation of an image never raises out of its module: the reason is logged and appended to `log/image_generation_failures.jsonl`.

**Audio: the Cartão never goes in mute.** The person asked for a Cartão with audio, and saying "Enviado" would be false. The Cartão becomes `failed` with a code (`tts_unreachable`, `tts_rejected`, `tts_empty`), no note is written, and Tentar de novo redoes it without paying the text again. The default voice is Google Translate called with the standard library only (the same request gTTS 2.5 makes, text split in pieces of up to 100 letters), with a reserve voice from OpenAI (`tts-1`, voice `alloy`, charged US$ 0.015 per thousand letters) used through the key, since the plan does not cover voice.

**Both.** The media goes from the network to the collection in the same turn as the new note and is never written under `user_files`, so there is nothing to clean in Apagar tudo or to ship in the diagnostic package. A duplicate or a repeated `guid` writes no media. The costs of an Envio outlive Apagar tudo, so they name the Cartão (`<phraseId>-<n>`), never the Termo, the Frase or the searches; the log carries the Cartão and a code, never what OpenAI or Google answered.

**Risks accepted.** Because search and write are one function, a Cartão that ends as a duplicate has already paid for the image judge and, if it came to that, the generation; an Envio interrupted between the image and the note asks for it again. The image calls use `urllib` and not the SDK, and the voice calls the same endpoint as gTTS, which Google can change and break gTTS and the Conexão together (the reserve covers it). The Google voice for the Termo at accent `com` returned 400 only on the owner's Mac, which is why the reserve exists. `col.media.write_data` was checked only against a fake `mw`, and the Qt image adapter only against PyQt6 without a screen, so a real Anki on the owner's Mac is still the proof.
