# The shortcut file of the login item is written byte by byte

"Abrir o Anki com o computador" is a LaunchAgent (a `.plist`) on the Mac and a shortcut in the Startup folder on Windows. The Windows `.lnk` is written byte by byte (MS-SHLLINK), because Anki's Python has no COM and PowerShell cannot be counted on. It carries the target list (`LinkTargetIDList`), the target (`LinkInfo`) and the working folder: without the list Windows refuses the shortcut ("no associated applications"). Outside ASCII the folder name goes in UTF-16, because in bytes of the ANSI page Windows does not find a folder whose name the page does not hold (not even cp1252 holds a name like "Ωμέγα"). An existing item that differs from what the Conexão would write now is rewritten (a shortcut of 0.4.21 onwards did not open the Anki, or an Anki that moved), but one is never created: a switch that is off stays off.
