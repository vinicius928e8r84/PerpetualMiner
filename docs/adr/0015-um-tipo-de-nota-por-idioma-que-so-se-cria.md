# One note type per Idioma, with all the fields, that the Conexão only creates

The Conexão com o Anki writes Cartões into a note type of its own per Idioma (`PerpetualMiner Inglês`, `PerpetualMiner Russo`) with our field names, so an Envio does not depend on the person's Anki having Basic/Front/Back.

**All fields are born together**, for every Nível, Frente and the Criação, and the note type has a single Cartão template. Changing the fields of a note type later forces the Anki to a full sync, and a second template changes `scm` and creates a new Cartão for each note (measured: `cards: 2`). The back carries the parts of every Nível, and each part shows only when its field has text. A consequence: changing the Frente rewrites that single template and the style of the note type, and nothing else (no note, no Cartão, no call to the AI, the voice or the photos), so a change the person made by hand to the template is lost. A note type that does not have exactly one template is left alone (`409 note_type_changed`). The two Lacuna fields (`Frase com lacuna`, `Dica`) are always written, whatever the Frente is at that moment, so that changing Frente costs nothing.

**The Conexão only creates; it never rewrites or deletes.** A note type that already has the name is not touched, whatever it contains, and the person's old Cartões and Baralhos are never renamed, converted or deleted. The Baralhos are created only in a new installation. A note type with our name but without our fields makes the Envio say `note_type_missing` and write nothing. The cost: a type created before a later Nível or part was added keeps the old back (the Iniciante's) until the person deletes it and the Conexão creates the new one, and adding a field to an existing type (the optional Significado simples of the Russo was added this way) asks for a full sync, which the owner accepted; when the type lacks an optional field, the Envio does not fail and puts its text at the end of the Definição.

**The Russo, owner's decisions.** The Iniciante has no dictionary Termo, for people who do not search i+1 because they lack the vocabulary. The Avançado is monolingual in Russian, with the Definição and the Significado simples in Russian and no morphology.

**A note type of the person's own.** Using a type the person already has creates and changes nothing in the collection; the Conexão writes only notes. The mapping lives in the extension and the Conexão only checks it. The Cartão has six parts: Frase, audio of the Frase, answer, Termo, audio of the Termo and image; the Frase and the answer are required and go in different fields. The person keeps the Frente their type already has, so the Frente chooser disappears and the Conexão does not rewrite their template. A missing or invalid mapping is refused before any spending of the key. Duplicates are found only if the Frase field holds only the Frase.

**Risks accepted.** The Produção is offered only at the Iniciante, the one Nível that fills the Tradução natural. The "✓ usou a palavra" of the Criação is computed in the Cartão with no AI and counts the Termo or its stem, so irregular forms do not count; this is the worker's reading, not yet confirmed by the owner. On the AnkiMobile and AnkiDroid only the ✓ works. Not proven: the owner's real Anki in English and Portuguese, Mac and Windows, sync with AnkiWeb and the mobile apps, and a real third-party type.
