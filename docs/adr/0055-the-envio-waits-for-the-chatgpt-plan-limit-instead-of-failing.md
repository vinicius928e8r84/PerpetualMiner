# The Envio waits for the ChatGPT plan limit instead of failing

When the plan refuses the text of a Card for a usage limit (`chatgpt_usage_limit`), the next ones would fail the same way, but nothing is lost: the Envio stays `running` and says `waiting: { reason: "plan_limit" }`, and the work thread asks again every `espera_do_plano` seconds, one request at a time. The wait is woken earlier only by Tentar de novo and by Usar a minha chave (`POST /jobs/usar-a-chave`, which marks the Envio `usingKey` and does the rest through the OpenAI key), and ended by Apagar tudo or by stopping the Conexão. A Card already in Anki, or with its text paid, is never asked again. The monthly cap works the same way before each Card: the Envio waits (`monthly_cap`) until the cap rises or the month turns.
