# Testes e ferramentas

O papel de `scripts/`, do complemento, dos testes de Node de `testes/`, do `e2e/`, das skills do repositório, do CI e do `preview/`. Lido sob demanda, não em toda sessão. Os arquivos da extensão estão em [extensao.md](extensao.md).

A regra `indice-de-arquivos` (`scripts/regras/indice-de-arquivos.js`) exige uma linha, aqui ou em `extensao.md`, para cada arquivo novo da raiz, de `lib/`, de `veio/` e do topo de `scripts/`, e acusa a linha que cita um arquivo que não existe mais.

| `scripts/regras/saude-do-codigo.js`, `scripts/regras/analisador/` | The rule `saude-do-codigo`: CodeScene's Code Health limits with one point of slack (complexity up to 8, nesting up to 3, one nested block per function, one logical operator per condition, 4 arguments, 69 lines per function, mean complexity below 4, 599 lines of code per Python file), counted as points above the limit per file and held by the ratchet of `linha-de-base.json`. A file's allowance is its own: no entry may rise above the base's, a new file is born within the limits, and only a file moved with `git mv` keeps its allowance. `analisador/medir-js.js` measures JavaScript with acorn (`analisador/nomes-js.js` names each function) (own `package.json`; `npm ci --prefix scripts/regras/analisador`, which the Regras and Testes rápidos jobs run), `analisador/medir_py.py` measures Python with the standard library's `ast` (one process for all files, `PYTHON` or `python3`), `analisador/pontos.js` turns the measures into points. The counting follows CodeScene's as checked on commit `351523da`: inside a named function a callback counts in that function, `?.`, `??`, `||=`, `&&=` and `??=` are branches, a nested Python `def` counts inside its parent. Outside a named function every function is measured on its own (a `test(...)` callback, an arrow in an object key, `module.exports = () => {}`, `export default`, a class property), and the loose code at the top of the file (with what a module's `(() => { … })()` wrapper holds) is one more unit, measured for complexity, nesting and conditions. Proofs: `scripts/regras/test_saude_do_codigo.js` (the ratchet, the calibration) and `scripts/regras/test_saude_do_codigo_medidas.js` (what is measured outside a named function) |
